# Research History

This directory gives the short version of how the project changed. The full experiment-by-experiment record remains in the project archive.

The project evolved through several successive hypotheses:

1. **Spectral perturbation of SGD noise.** Controlled Duffing tests established that the spectral machinery can work under enforced assumptions.
2. **Noise amplitude as explanation.** Additive-noise controls showed that amplitude alone is insufficient.
3. **Temporal covariance / SGD memory.** Attractive in early experiments, then downgraded after filtration and repaired fixed-state audits.
4. **State-dependent noise geometry.** Produced the main analytical and controlled numerical v1 results.
5. **Higher-order local descriptors.** Produced measurable candidates but the preregistered neural `chi_mix` test failed its regime-robust success criteria.
6. **Finite-step spectral closure / descriptor sufficiency.** Late proof work shifted the question from “find another term” to “what information is sufficient for a specified observable, horizon and order?”

Complete proof logs, failed hypotheses, experiment archives, and the chronological record remain in the project archive and are not duplicated here.
