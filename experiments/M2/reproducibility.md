# M2 reproducibility notes

## Objective

Test whether temporal organization of stochastic gradient noise changes finite-horizon covariance geometry beyond matched one-step statistics.

## Controls

The analysis should compare temporal structure against marginally matched baselines.

## Required metadata

- sampling procedure
- temporal ordering protocol
- random seeds
- configuration
- covariance metrics
- uncertainty estimates

Large trajectory archives and generated arrays are distributed separately from the source repository.
