# M2 public source provenance

The working project retains the archived execution source for the random-reshuffling temporal-covariance experiment. A portable public source was prepared while preserving the scientific protocol.

Portability changes are limited to:

- replacing environment-specific storage paths with configurable local roots;
- replacing the archived M1 location with the public M1 experiment reference;
- removing notebook-specific source capture;
- preserving seeds, sampling rules, horizons, temporal diagnostics, checkpoint logic and numerical decision logic.

Prepared public source SHA-256:

`3c951895b08e4ccad4ae6aa4bdbcc16afe44117149d4b78a4298c2c6fef2dbb8`

The public configuration in this directory records the completed protocol settings. Large per-example gradient banks, checkpoints and generated arrays remain outside normal Git history.
