# M1 reproducibility notes

## Objective

Evaluate finite-horizon covariance propagation under an i.i.d. minibatching assumption.

## Public artifact policy

The repository stores experiment descriptions, configurations and compact summaries. Large generated tensors and checkpoints are kept outside the main Git history.

## Required metadata

- configuration
- random seeds
- model specification
- evaluation metrics
- generated figures and tables

The exact archived execution source should be added together with its configuration snapshot when released.
