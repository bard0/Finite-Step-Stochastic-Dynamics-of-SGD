# M1 public source provenance

The working project retains the archived execution source used for the reported M1 run. A portable public source was prepared without changing the scientific calculation.

Public-source portability changes are limited to:

- replacing environment-specific absolute storage paths with configurable local roots;
- removing notebook-specific source capture;
- retaining deterministic seeds, numerical settings, checkpoint logic, metrics and decision rules.

Prepared public source SHA-256:

`ac23a762b3ffa33abca49d250f729fc994dd8899646b7cf3a3120d65c1e8962d`

The public configuration and compact result tables in this directory are taken from the completed full run. Large raw arrays and checkpoints remain outside normal Git history.
