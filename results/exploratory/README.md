# Exploratory results

Results in this category are informative but are not yet promoted to broad claims.

- **M7 — temporal-ordering causal ablation.** The controlled linear component shows a substantial change in off-diagonal temporal covariance and finite-horizon covariance when temporal ordering is destroyed. The neural component is retained under a preregistered analysis boundary and is not assigned an automated scientific verdict. See `../../experiments/M7/results/` and `../../experiments/M7/causal_design.md`.

M7 should be interpreted as causal-design evidence in tested controls, not as proof of a universal temporal-memory mechanism in neural SGD.
