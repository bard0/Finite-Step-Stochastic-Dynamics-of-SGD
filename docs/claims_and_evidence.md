# Claims and evidence

## Supported claims

The strongest current claim is that temporal organization of SGD gradient noise can provide predictive information about finite-horizon stochastic covariance geometry beyond matched marginal noise statistics in tested regimes.

## Evidence status

| Stage | Status |
|---|---|
| 3I-R | validated mechanism |
| 3J | no resolved residual beyond tested correction |
| 3K | supported held-out prediction in tested regime |
| M1 | supported finite-horizon covariance prediction |
| M2 | supported temporal covariance effect in tested setting |
| M3-M6 | robustness and mechanism validation |
| M7/T1 | causal validation frontier |

## Explicit non-claims

- no universal SGD law
- no claim of discovering SGD memory
- no universal generalization improvement
- no complete spectral closure of SGD
