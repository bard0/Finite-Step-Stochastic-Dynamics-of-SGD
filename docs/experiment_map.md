## Interpretation rule

The historical line is preserved, but only the current evidence ledger determines promoted claims. Engineering feasibility, exploratory heterogeneity, and confirmatory predictive success are separate statuses.

Each public experiment record should preserve enough configuration, seeds, metrics, and provenance to reconstruct the scientific decision while keeping large raw artifacts outside normal Git history.
